SENTINEL
ECS PROJECT · 2026–27

Reliable navigation starts with knowing when to trust the signal.

SENTINEL is a GNSS integrity monitoring prototype designed to identify suspicious navigation conditions such as signal jamming, spoofing, and loss of satellite signal. It compares satellite navigation information with motion data from an inertial sensor.

Concept diagram only — final data depends on the connected hardware and firmware.

What SENTINEL checks

Three navigation conditions the prototype is designed to flag.

⌁

Signal jamming

Looks for signs of unusually weak or unavailable satellite signals that may indicate interference.

◎

Possible spoofing

Checks for suspicious differences between GNSS movement and the motion measured by the IMU.

◷

Signal loss

Reports when satellite navigation data is unavailable, while inertial data can help track short-term motion.

Prototype note: This website currently uses demonstration data. It is not connected to the ESP32 or live GNSS hardware, so the dashboard values and simulation alerts are not real measurements.
